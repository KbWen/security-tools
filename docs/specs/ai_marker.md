# E4-F2: AI-Generated Code Marker

## Problem Description
As AI coding assistants are widely used, organizations need transparency regarding AI-authored contributions. Untracked and unreviewed AI code raises licensing (copyleft) and security (hallucination/vulnerabilities) risks.

## Proposed Capabilities
1. **Source Comment Scanning**: Detect comment headers indicating AI tool generation (e.g., `Generated by Copilot`, `Auto-generated by Claude`).
2. **Git Commit History Auditing**: Scan git history programmatically for AI co-author signatures (e.g. `Co-authored-by: Copilot`) and check for human review metadata (e.g. `Reviewed-by:`).

## Acceptance Criteria
* [ ] Scans source code files (`.py`, `.js`, `.ts`, `.go`, `.java`, etc.) for AI comment signatures and raises `INFO` findings.
* [ ] Runs a git log query programmatically to identify AI co-authored commits.
* [ ] Raises a `MEDIUM` severity warning for AI co-authored commits that lack human review trailers (like `Reviewed-by:` or `Approved-by:`).
* [ ] Integrates into standard scanning workflows without crashing if git is missing or not a git repository.

## Non-goals
* Performing ML-based perplexity analysis on code blocks.
