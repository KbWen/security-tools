# Security Policy

## Supported Versions

We currently only support the latest stable version of GhostCheck.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is the core of GhostCheck. If you find a security vulnerability, please do NOT open a public issue. Instead, follow these steps:

1. Send an email to **kbwen@example.com** with the subject "SECURITY VULNERABILITY - [Short Summary]".
2. Include a detailed description of the vulnerability, steps to reproduce, and potential impact.
3. We will acknowledge your report within 48 hours and provide a timeline for a fix.

Once we have verified and patched the vulnerability, we will coordinate a public disclosure with you and credit your contribution.

Thank you for helping keep GhostCheck and its users safe!
